# Apna Cafe ☕✨

A Hogwarts-inspired café website created by **Rinaad Fatima** using HTML and CSS.

🌐 **[Visit the live website](https://rinaad26.github.io/Apna--Cafe/)**

## About the project

Apna Cafe is a themed café website inspired by the magical atmosphere of the Wizarding World. It brings together a welcome page, a themed café menu, Hogwarts house-inspired content, an image gallery, and the story behind the project.

## Website sections

- **The Great Hall** — welcome section and café introduction.
- **The Potions Menu** — signature drinks, magical bites, and house-special doughnuts.
- **The Wizard's Corner** — Hogwarts house descriptions and image gallery.
- **The Story Behind the Magic** — the inspiration and creator story.

## Built with

- HTML5
- CSS3

This is a static front-end website. It does not currently use JavaScript or a backend.

## Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Rinaad26/Apna--Cafe.git
   ```

2. Open the downloaded `Apna--Cafe` folder.
3. Open `index.html` in your browser.

No package installation or build step is required.
